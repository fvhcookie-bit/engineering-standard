# Q-19 «Аудит исключений и классов проектов» (ночной L4-гейт)

**Критерий:** `QUALITY_GATES.md` Q-19, `EXCEPTIONS_POLICY.md` §6–7 · **TASK:** §3.2 ·
**Сценарии:** Б-3 (совместно с Q-11), Б-17…Б-20

## Назначение
Ночной аудит всего дерева: якоря `EX-…` в коде ↔ реестр `EXCEPTIONS.md`;
просрочки «Срок пересмотра»; кумуляция исключений одного принципа → автозадача
E-D; доля К3-кода против лимитов (§0.6 EP: дефолт ≤ 20%, алерт с 16%).

## Входы
- дерево head (`RepoFiles.list_files`), `EXCEPTIONS.md`, `REPO_CLASS` — через `Registries`;
- config: `today` (дата — подаётся явно, детерминизм), `k3_limit` (0.20), `k3_alert` (0.16).

## Коды findings
`ANCHOR_WITHOUT_ENTRY` · `ENTRY_WITHOUT_ANCHOR` · `EXPIRED_EXCEPTION` ·
`AUTO_TASK_ED` (info — автозадача E-D) · `K3_LIMIT_EXCEEDED` · `K3_LIMIT_ALERT` (warning).

## Ограничения (честно)
- «якорь старше 1 рабочего дня без записи» сейчас детектируется безусловно
  (грейс по git-возрасту якоря —future: нужен git blame, отложено);
- автозадача E-D фиксируется в отчёте (`AUTO_TASK_ED`); вызов API трекера —
  при подключении конкретного адаптера трекера (TASK §3.2 п.3);
- `REPO_CLASS`: доли К3 считаются по строкам-соглашению `k3_globs = glob, glob`.
- Ослабление гейта — никак, кроме E-D (`EXCEPTIONS_POLICY.md`).
