# Q-16 «Границы задачи» (диф-гигиена)

**Критерий:** `QUALITY_GATES.md` Q-16 · **TASK:** §3.5 · **Сценарии:** Б-13, Б-14

## Назначение
Список нужных файлов берётся из трекера по ID задачи — не из описания PR.
- файл вне списка → FAIL `SCOPE_OUTSIDE_TASK` (Б-14);
- списка нет в задаче → `SKIP` с явной причиной (Б-13) — гейт не применяется,
  остаётся сигнальный режим;
- диф > 600 добавленных строк вне механических изменений → warning
  `LARGE_DIFF` (предложить декомпозицию);
- трекер недоступен → `UNAVAILABLE` (fail-closed).

## Конфиг
`task_id` (из имени ветки/задачи), `mechanical_globs` (форматирование, rename,
регенерация — §0.7 EP), `line_limit` (600).

## Ограничения
Список файлов задачи — соглашение с трекером (TASK §2); подключение конкретного
трекера — адаптер (`get_task_files`), сейчас — заглушки fake/github.
