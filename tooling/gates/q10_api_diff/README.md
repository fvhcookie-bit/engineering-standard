# Q-10 «api-diff и совместимость» (обёртка)

**Критерий:** `QUALITY_GATES.md` Q-10 · **TASK:** §3.6 · **Сценарии:** Б-21

## Назначение
Запускает внешний инструмент сравнения публичных поверхностей для каждого
затронутого языка. Результат инструмента — JSON-список изменений
(`{"path", "symbol", "kind": "api-change" | "breaking"}`). Метки
`api-change`/`breaking` ставит гейт, не автор PR.

**Язык без инструмента → UNAVAILABLE с причиной — не молчаливый OK.**
Сбой инструмента → UNAVAILABLE (fail-closed).

## Конфиг
| Ключ | Смысл |
|---|---|
| `tools` | `[{language, cmd}]` — команда инструмента (шаблоны `{base}`/`{head}`); только из доверенного конфига |
| `language_ext` | маппинг расширений на языки |
| `base`, `head` | сравниваемые ревизии |

## Коды findings
`API_BREAKING` (error, метка `breaking` + второй проверяющий) ·
`API_CHANGE` (warning, метка `api-change`).

## Ограничения
- Инструменты экосистем — из матрицы `IMPLEMENTATION_GUIDE` §2 (kotlin-api-diff,
  cargo public-api, go-apidiff, griffe, api-extractor, buf/oasdiff); Python —
  ограничения по строгим типам помечаются инструментом.
- Команда инструмента — из конфига companion (доверенный источник); содержимое
  целевого репозитория в командную строку не передаётся.
