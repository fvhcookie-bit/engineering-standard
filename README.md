# Engineering Standard

Инженерный стандарт для ИИ-ассистированной гражданской разработки ПО (v1.2)
и слой принуждения (guard-гейты) к нему.

**План развития:** см. [ROADMAP.md](ROADMAP.md).

## Структура

| Папка | Содержимое |
|---|---|
| корень | `CHANGELOG.md` — единая история версий стандарта и runner'а (A-4); `MATURITY.md` + `MATURITY_HISTORY.md` — метрика зрелости (D-3); `ROADMAP.md` — план развития |
| `standards/` | Нормативное ядро стандарта (v1.2) — см. список документов ниже |
| `standards/review/` | Архив независимых ревью v1.0 (4 обзора, 2026-11-13) + `REVIEWS_STATUS.md` (статусы 107 находок) + карта сокращения v1.2 |
| `guidelines/` | Задание и гайдлайны слоя принуждения `gate-runner` (этапы M1–M4, матрица Б-1…Б-24) |
| `tools/` | Служебные скрипты репозитория: `doc_consistency.py` — консистентность собственных документов (A-3; CI — `.github/workflows/consistency.yml`), `build_digest.py` — ИИ-дайджест (B-9), `maturity.py` — метрика зрелости (D-3) |
| `tooling/` | **gate-runner** — исполняемый слой принуждения (companion; monorepo-решение владельца 2026-11-17; CI — `.github/workflows/tooling.yml`) |

> Исходное задание стандарта (PDF) хранится вне репозитория; ссылки вида `user/P10.pdf` в TRACEABILITY относятся к локальному архиву владельца.

## Документы стандарта (`standards/`)

1. **ENGINEERING_PRINCIPLES.md** — 55 принципов по доменам A–H (48 живых после слияний v1.2; прочие — заглушки для трассировки); классы проектов К1–К3 (`REPO_CLASS`); несущие термины (§0.7).
2. **QUALITY_GATES.md** — исполняемая модель проверок: уровни L0–L4, правило храповика, каталог гейтов Q-01…Q-19.
3. **AI_AGENT_RULES.md** — правила работы ИИ-агента: границы задачи, prompt-injection защита, стоп-условия, чек-лист PR.
4. **EXCEPTIONS_POLICY.md** — таксономия отступлений E-A…E-D, матрица подписантов, последствия нарушений.
5. **IMPLEMENTATION_GUIDE.md** — порядок внедрения: 7 этапов, метрики успеха, анти-паттерны.
6. **TRACEABILITY.md** — трассировка к правилам NASA Power of 10 (история версий — в [CHANGELOG.md](CHANGELOG.md)); якоря цитат оригинала для механической сверки.

## Слой принуждения (`guidelines/`)

- **TASK_guard-gates.md** — ТЗ на companion (слой принуждения `gate-runner`): этапы M1–M4, матрица приёмочных сценариев-обходов Б-1…Б-24.
- **GUIDELINE_development.md** — архитектура runner'а, контракт гейта, правило независимых источников.
- **GUIDELINE_profiles_and_dictionaries.md** — профили линтеров, словари подавлений, config-fingerprint.

## Сопутствующие репозитории

- **gate-runner** — реализация guard-гейтов (Q-10, Q-11, Q-12, Q-15, Q-16, Q-17, Q-18, Q-19, L0-периметр; профили, словари 7 экосистем, агрегатор метрик). Развивается в этом же репозитории: каталог `tooling/`, теги `runner-vN` (monorepo-решение владельца 2026-11-17; извлечение — при появлении внешних потребителей). См. `guidelines/TASK_guard-gates.md` и `tooling/README.md`.
