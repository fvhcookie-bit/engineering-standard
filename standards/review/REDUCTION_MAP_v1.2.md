## 1. Критерии (утверждены в плане блока B)

- **Слияние** — только если: одинаковая цель контроля + одна и та же опора в гейтах + ни одной уникальной ссылки на гейты. Выживший наследует **сильнейший** класс из слитых.
- **Понижение [ОБЯЗ]→[РЕК]** — только если: принцип не опирается ни одним блокирующим гейтом и уже исполняется исключительно ревью (честная маркировка, см. QG §6 «метрика зрелости»).
- **Инварианты:** ни один ID не перенумеровывается (слитые — заглушки «слит с X»); ни один блокирующий гейт не остаётся без опоры; G-домен и H-домен не трогаются; F6 правится задачей B-3, вне B-1.
